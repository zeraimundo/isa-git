Debian e derivados

apt trabalha sobre dpkg

dpkg

Camada local

Instala e consulta arquivos .deb. Mantém o banco de pacotes locais, mas não pesquisa repositórios nem resolve dependências remotas sozinho.

apt

Camada de repositórios

Sincroniza catálogos, resolve dependências, baixa pacotes e chama o dpkg para aplicar a transação.

dpkg

Consultas ao banco local

  • dpkg -l lista pacotes conhecidos.
  • dpkg -s nome mostra o estado.
  • dpkg -L nome lista arquivos instalados.
  • dpkg -S /caminho identifica o pacote dono do arquivo.
  • dpkg -I arquivo.deb mostra metadados.
aluno@debian:~$ dpkg -s bash
Status: install ok installed
Version: 5.2.15-2+b9

aluno@debian:~$ dpkg -S /bin/ls
coreutils: /bin/ls
# instalar arquivo local
root@debian:~# dpkg -i programa.deb

# concluir configurações interrompidas
root@debian:~# dpkg --configure -a

# remover ou eliminar configurações
root@debian:~# dpkg -r programa
root@debian:~# dpkg -P programa
dpkg

Operações de baixo nível

Dependência ausente

dpkg -i pode deixar o pacote sem configuração completa. Use apt --fix-broken install para resolver dependências pelos repositórios.

Para um arquivo local, apt install ./programa.deb costuma ser a escolha mais simples.

APT

update e upgrade fazem trabalhos diferentes

apt update

Atualiza o catálogo

Baixa metadados dos repositórios configurados. Não instala novas versões dos programas por si só.

apt upgrade

Atualiza pacotes instalados

Calcula e aplica versões disponíveis sem remover pacotes para concluir a atualização.

aluno@debian:~$ sudo apt update
aluno@debian:~$ apt list --upgradable
aluno@debian:~$ sudo apt upgrade
APT

Instalação e remoção

remove preserva arquivos de configuração tratados como conffiles. purge também remove essas configurações do pacote.

autoremove mostra dependências que ficaram sem uso. Leia a lista antes de confirmar.
aluno@debian:~$ sudo apt install tree
aluno@debian:~$ sudo apt remove tree
aluno@debian:~$ sudo apt purge tree
aluno@debian:~$ sudo apt autoremove
aluno@debian:~$ sudo apt clean
aluno@debian:~$ apt search editor
aluno@debian:~$ apt show vim
aluno@debian:~$ apt policy vim
aluno@debian:~$ apt depends vim
aluno@debian:~$ apt list --installed
APT

Pesquisa antes da instalação

  • Confirme o nome do pacote.
  • Leia descrição e dependências.
  • Confira versão candidata e repositório.
  • Observe arquitetura e tamanho.
APT e arquivo local

Instalação de um arquivo .deb

dpkg -i programa.deb

Instala o arquivo diretamente. Dependências ausentes exigem uma etapa posterior.

apt install ./programa.deb

Reconhece o caminho local e tenta resolver dependências nos repositórios habilitados.

aluno@debian:~/Downloads$ sudo apt install ./programa.deb
# o prefixo ./ diferencia arquivo local de nome de pacote
Repositórios Debian

Arquivos de fontes

O APT lê /etc/apt/sources.list e arquivos em /etc/apt/sources.list.d/. Sistemas atuais também usam o formato deb822 com extensão .sources.

Use arquivos separados para fornecedores externos e associe cada fonte à sua chave com Signed-By.

Types: deb
URIs: https://deb.debian.org/debian
Suites: trixie trixie-updates
Components: main
Signed-By: /usr/share/keyrings/debian-archive-keyring.gpg

root@debian:~# apt update
Fedora e RHEL

RPM, YUM e DNF

rpm

Camada de baixo nível para arquivos .rpm e banco local.

yum

Gerenciador histórico de repositórios da família Red Hat.

dnf

Sucessor do YUM, com resolução de dependências, repositórios e histórico de transações.

Em sistemas RHEL modernos, o comando yum pode atuar como interface compatível para o DNF.

Compatibilidade

Comandos semelhantes em YUM e DNF

TarefaYUMDNF
Instalaryum install treednf install tree
Removeryum remove treednf remove tree
Pesquisaryum search treednf search tree
Atualizaryum updatednf upgrade
Repositóriosyum repolistdnf repolist
Para novos materiais e sistemas atuais, prefira a documentação e a sintaxe do dnf.
DNF

Rotina de instalação

  • search procura por nome e descrição.
  • info mostra versão, origem e tamanho.
  • install resolve a transação.
  • remove calcula o impacto da remoção.
  • autoremove limpa dependências sem uso.
aluno@fedora:~$ dnf search tree
aluno@fedora:~$ dnf info tree
aluno@fedora:~$ sudo dnf install tree
aluno@fedora:~$ sudo dnf remove tree
aluno@fedora:~$ sudo dnf autoremove
aluno@fedora:~$ dnf check-upgrade
aluno@fedora:~$ sudo dnf upgrade
aluno@fedora:~$ dnf repolist
aluno@fedora:~$ dnf repoinfo
aluno@fedora:~$ dnf history
aluno@fedora:~$ dnf provides '*/semanage'
DNF

Atualização, origem e histórico

O histórico permite auditar transações. provides descobre qual pacote entrega um arquivo ou recurso.

-y aceita todas as confirmações. Use somente quando a transação já foi revisada ou em automação controlada.
DNF e arquivo local

Instalação de um arquivo .rpm

rpm -i programa.rpm

Opera em baixo nível. Pode informar dependências ausentes sem buscá-las automaticamente.

dnf install ./programa.rpm

Instala o arquivo e tenta obter dependências nos repositórios configurados.

aluno@fedora:~/Downloads$ sudo dnf install ./programa.rpm
# confira fornecedor, assinatura e arquitetura antes
Arch Linux

Pacman combina sincronização e banco local

-S

Sync

Sincroniza e instala pacotes dos repositórios.

-R

Remove

Remove pacotes instalados.

-Q

Query

Consulta o banco local de pacotes.

As letras podem ser combinadas. -Syu sincroniza os catálogos e atualiza todo o sistema.

Pacman

Pesquisa, instalação e atualização

  • -Ss pesquisa nos repositórios.
  • -Si mostra informações remotas.
  • -S instala um pacote.
  • -Syu atualiza catálogos e sistema.
  • -U instala um arquivo local.
aluno@arch:~$ pacman -Ss tree
aluno@arch:~$ pacman -Si tree
aluno@arch:~$ sudo pacman -S tree
aluno@arch:~$ sudo pacman -Syu
aluno@arch:~$ sudo pacman -U ./pacote.pkg.tar.zst
aluno@arch:~$ sudo pacman -R tree
aluno@arch:~$ sudo pacman -Rs tree
aluno@arch:~$ sudo pacman -Rns tree

aluno@arch:~$ pacman -Q
aluno@arch:~$ pacman -Qi bash
aluno@arch:~$ pacman -Qo /usr/bin/ls
Pacman

Remoção e banco local

-Rs inclui dependências que ficaram sem uso. -Rns acrescenta a remoção de arquivos de configuração não modificados controlados pelo pacote.

Leia a transação completa antes de confirmar uma remoção recursiva.
Arch Linux

Atualização completa do sistema

pacman -Sy pacote

Atualiza apenas o catálogo e pode instalar um pacote novo sobre um sistema antigo. Essa combinação cria uma atualização parcial.

pacman -Syu

Sincroniza catálogos e atualiza o conjunto instalado para versões compatíveis entre si.

O Arch Linux não oferece suporte a atualizações parciais. Leia os avisos da distribuição antes de grandes atualizações.

Diagnóstico

Problemas frequentes

Debian

dpkg --configure -a
apt --fix-broken install
apt update

Fedora e RHEL

dnf check
dnf clean all
dnf makecache

Arch

pacman -Syu
pacman -Qk pacote
pacman -Dk

Arquivos de bloqueio: não os apague automaticamente. Primeiro confirme que nenhum gerenciador está executando e investigue por que a transação foi interrompida.
Administração

Boas práticas de gerenciamento

  • Use os repositórios oficiais sempre que possível.
  • Confira assinatura, fornecedor e arquitetura de arquivos locais.
  • Leia o resumo da transação antes de confirmar.
  • Atualize o catálogo antes de pesquisar versões recentes.
  • Evite misturar repositórios de versões diferentes.
  • Não desative verificação GPG para “resolver” erros.
  • Mantenha registros de fontes externas adicionadas.
  • Teste automações em ambiente isolado antes da produção.
Laboratório

Instalação e remoção do tree

1. Identificação

Leia /etc/os-release e identifique a família da distribuição.

2. Pesquisa

Pesquise tree, examine descrição, versão, repositório e tamanho.

3. Instalação

Instale o pacote, execute tree --version e descubra quais arquivos foram instalados.

4. Atualizações

Liste atualizações disponíveis sem aplicá-las automaticamente.

5. Remoção

Simule ou revise a transação e remova o pacote.

6. Registro

Entregue comandos, saídas e uma comparação com outra família.
