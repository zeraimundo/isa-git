Anatomia e execução

Texto + interpretador + permissão

#!/usr/bin/env bash

projeto="api-pedidos"
printf 'Verificando %s...\n' "$projeto"

#! define o interpretador. env procura o Bash no PATH. Aspas protegem espaços e curingas.

bash ola.sh
chmod +x ola.sh
./ola.sh

Em sala

Crie ola.sh, altere o projeto e compare as três formas de execução. Por que ./ é necessário?

Contrato entre programas

Códigos de saída: sucesso é zero

mkdir -p build
cp app.jar build/
status=$?

if (( status == 0 )); then
  echo "artefato preparado"
else
  echo "falha na cópia" >&2
fi
exit "$status"

$?

Guarda o status do último comando: 0 é sucesso; outro valor é falha.

CI, Docker e systemd usam esse contrato para decidir o próximo passo.

Teste: execute false; echo $? e true; echo $?.

Parâmetros automáticos

Uma ferramenta de linha de comando

#!/usr/bin/env bash
arquivo=${1:-app.log}
nivel=${2:-ERROR}

printf 'Script: %s\n' "$0"
printf 'Argumentos: %s\n' "$#"
grep "$nivel" "$arquivo"
  • $0: script
  • $1…$9: argumentos
  • $#: quantidade
  • "$@": todos preservados
  • $$: PID

Experimente: ./filtra.sh servidor.log WARN.

Entrada, validação e aritmética

Valide antes de agir

read -r -p "Ambiente [dev]: " ambiente
ambiente=${ambiente:-dev}

if [[ ! "$ambiente" =~ ^(dev|homolog|prod)$ ]]; then
  echo "Ambiente inválido" >&2
  exit 2
fi
tentativas=3
falhas=1
restantes=$((tentativas - falhas))
((falhas++))

if (( restantes > 0 )); then
  echo "tentar novamente"
fi

Nunca concatene entrada não validada em comandos. Bash calcula inteiros; para decimais, componha com awk.

Laços

for percorre; while reage

falhou=0
for arquivo in configs/*.json; do
  jq empty "$arquivo" || {
    echo "inválido: $arquivo"
    falhou=1
  }
done
exit "$falhou"
tentativa=1
while (( tentativa <= 5 )); do
  curl -fsS localhost:8080/health \
    && break
  sleep "$tentativa"
  ((tentativa++))
done

Aplicações reais: validar configurações antes do deploy e repetir health checks com espera progressiva.

Funções

Separe responsabilidades

log() { printf '[%(%H:%M:%S)T] %s\n' -1 "$*"; }

exigir() {
  command -v "$1" >/dev/null 2>&1 || {
    log "dependência ausente: $1"
    return 1
  }
}

main() {
  exigir git
  exigir shellcheck
  log "ambiente aprovado"
}
main "$@"

local evita vazamento. return comunica status; saída textual não substitui esse contrato.

Arrays

Preserve cada argumento exatamente

servicos=(api worker frontend)

for servico in "${servicos[@]}"; do
  printf 'Testando %s\n' "$servico"
  "./test-$servico.sh"
done

Uma string com espaços não é uma lista segura. Arrays mantêm cada elemento separado.

comando=(curl -fsS --max-time 5)
"${comando[@]}" "$url"

echo "${#servicos[@]} serviços"
Falhas seguras

Temporários, trap e modo estrito

#!/usr/bin/env bash
set -Eeuo pipefail

tmp=$(mktemp -d)
cleanup() { rm -rf -- "$tmp"; }
trap cleanup EXIT
trap 'echo "falha na linha $LINENO" >&2' ERR

cp config/*.json "$tmp/"
tar -czf backup.tgz -C "$tmp" .

-e

interrompe falhas não tratadas

-u

rejeita variável indefinida

pipefail

propaga falha do pipeline

Projeto integrador

Implementação verificável

#!/usr/bin/env bash
set -Eeuo pipefail
projeto=${1:?uso: $0 DIRETORIO TAG}
tag=${2:?informe a tag, exemplo: v1.2.0}

[[ "$tag" =~ ^v[0-9]+\.[0-9]+\.[0-9]+$ ]] ||
  { echo "tag inválida" >&2; exit 2; }
[[ -d "$projeto/.git" ]] ||
  { echo "não é repositório" >&2; exit 3; }

for cmd in git tar sha256sum; do
  command -v "$cmd" >/dev/null ||
    { echo "falta: $cmd" >&2; exit 4; }
done
git -C "$projeto" diff --quiet ||
  { echo "há alterações locais" >&2; exit 5; }

mkdir -p dist
nome=$(basename "$projeto")
artefato="dist/${nome}-${tag}.tar.gz"
tar --exclude=.git -czf "$artefato" \
  -C "$(dirname "$projeto")" "$nome"
sha256sum "$artefato" > "${artefato}.sha256"
printf 'Release criada: %s\n' "$artefato"
Atividade guiada

Observabilidade de uma API

Desafio em equipes — 35 minutos

  1. Crie 12 linhas com data, nível, endpoint e latência.
  2. Receba o arquivo por $1 e valide sua existência.
  3. Conte INFO, WARN e ERROR.
  4. Com awk, calcule a média por endpoint.
  5. Gere relatorio-TIMESTAMP.txt; erros vão para stderr.
  6. Retorne 1 se houver ERROR; caso contrário, 0.

Uma equipe cria o log, outra o analisador e outra os testes. Depois, trocam os arquivos.

Práticas profissionais

Checklist antes de versionar

  • variáveis entre aspas;
  • printf e stderr;
  • status significativo;
  • mktemp e trap;
  • alvos destrutivos validados.
  • shellcheck script.sh;
  • bash -n script.sh;
  • funções pequenas e main "$@";
  • README com exemplos;
  • código versionado e revisado.
