Objetivo da aula

Reunir comandos conhecidos em scripts

Antes

O estudante digita cada comando manualmente e precisa lembrar a ordem.

Com o script

O arquivo registra a ordem, recebe dados e repete a tarefa quando necessário.

Resultado

A mesma atividade pode ser testada, corrigida e executada novamente.

Nesta aula não usaremos sed nem awk. O foco permanece nos comandos já estudados pela turma.

Primeiro script

O interpretador #!/bin/bash

#!/bin/bash

echo "Olá, turma de ISA!"
echo "O script começou."
ParteSignificado
#!Shebang. Informa qual programa interpretará o arquivo.
/bin/bashCaminho do Bash no Debian 13.
echoExibe texto ou o valor de uma variável.

Regra da aula: todos os scripts começarão exatamente com #!/bin/bash.

Criar e executar

Do editor ao terminal

nano primeiro.sh
chmod +x primeiro.sh
./primeiro.sh
Comando ou símboloExplicação
nano primeiro.shAbre ou cria o arquivo no editor Nano.
chmodChange mode. Altera permissões.
+x+ adiciona uma permissão. x significa execução.
./Indica que o arquivo está no diretório atual.

Teste

Remova a permissão com chmod -x primeiro.sh. O sinal - retira a permissão. Depois, adicione-a novamente.

Comentários e ordem

O Bash lê de cima para baixo

#!/bin/bash

# Esta linha é um comentário.
echo "1. Criando o diretório"
mkdir aula_shell

echo "2. Entrando no diretório"
cd aula_shell

echo "3. Criando o arquivo"
touch anotacoes.txt
ElementoFunção
# textoComentário. O Bash ignora essa linha. A primeira linha é a exceção por conter o shebang.
mkdirMake directory. Cria um diretório.
cdChange directory. Muda o diretório atual.
touchCria um arquivo vazio ou atualiza sua data.
Variáveis

Guardar um valor para reutilizar

#!/bin/bash

pasta="atividade_isa"
arquivo="resultado.txt"

mkdir "$pasta"
touch "$pasta/$arquivo"
echo "Arquivo criado em: $pasta/$arquivo"
FormaExplicação
pasta="valor"Cria a variável. Não coloque espaços antes ou depois de =.
$pastaO cifrão pede ao Bash o valor guardado.
"$pasta"As aspas mantêm o valor como um único argumento, mesmo com espaços.
Entrada pelo teclado

read permite conversar com o script

#!/bin/bash

read -r -p "Digite seu nome: " nome
echo "Olá, $nome!"
ParteSignificado
readLê o que o usuário digitar.
-rA letra r vem de raw. Mantém barras invertidas como texto.
-pA letra p vem de prompt. Mostra uma mensagem antes da leitura.
nomeVariável que recebe o texto digitado.

Altere

Peça também a matrícula e mostre os dois valores em uma frase.

Argumentos

Dados informados na execução

#!/bin/bash

echo "Nome do script: $0"
echo "Primeiro argumento: $1"
echo "Segundo argumento: $2"
echo "Quantidade: $#"
echo "Todos: $@"
./argumentos.sh aluno atividade_01
Variável automáticaValor neste exemplo
$0./argumentos.sh
$1 e $2aluno e atividade_01
$#2. O símbolo # representa a quantidade.
"$@"Todos os argumentos, mantendo cada um separado.
Valores padrão

O script pode funcionar sem argumento

#!/bin/bash

pasta=${1:-atividade_isa}
echo "A pasta será: $pasta"
mkdir -p "$pasta"
FormaExplicação
${1:-atividade_isa}Usa $1. Se estiver vazio, usa atividade_isa.
:-Operador de valor padrão.
mkdir -pp vem de parents. Cria diretórios intermediários e não reclama se a pasta já existir.
Testes

Verificar antes de continuar

#!/bin/bash

pasta=${1:-atividade_isa}

if [[ -d "$pasta" ]]; then
  echo "O diretório existe."
else
  echo "O diretório não existe."
fi
ParteExplicação
ifInicia a decisão: “se a condição for verdadeira”.
[[ ... ]]Área em que o Bash avalia a condição.
-dA letra d significa directory. Testa se o caminho é um diretório.
thenInicia os comandos do resultado verdadeiro.
elseInicia a alternativa falsa.
fiFecha o bloco if.
Testes de arquivos

As letras mais úteis em [[ ]]

TestePergunta feita pelo Bash
-e caminhoe de exists: o caminho existe?
-f arquivof de file: é um arquivo comum?
-d pastad de directory: é um diretório?
-r arquivor de read: há permissão de leitura?
-w arquivow de write: há permissão de escrita?
-x arquivox de execute: há permissão de execução?
-z "$texto"z de zero: a string está vazia?

O hífen faz parte da opção. Ele indica que a letra modifica o teste ou o comando.

Status e encadeamento

O resultado do comando

#!/bin/bash

mkdir -p atividade
echo "Código retornado: $?"

cd atividade && touch ok.txt
cd pasta_inexistente || echo "Não foi possível entrar."
SímboloExplicação
$?Código do comando anterior. Zero significa sucesso. Outro número indica erro.
&&Executa o próximo comando somente se o anterior funcionar.
||Executa o próximo comando somente se o anterior falhar.
Repetição com for

Criar vários arquivos

#!/bin/bash

for numero in 1 2 3
do
  touch "relatorio$numero.txt"
  echo "Criado: relatorio$numero.txt"
done
PalavraExplicação
forInicia a repetição.
numeroRecebe um valor por vez: 1, depois 2, depois 3.
inApresenta a lista que será percorrida.
doInicia os comandos repetidos.
doneEncerra o laço.
Curingas em scripts

Selecionar grupos de arquivos

#!/bin/bash

mkdir -p backup
cp *.txt backup/
ls -l backup/
ParteExplicação
*.txt* representa qualquer quantidade de caracteres. Seleciona todos os nomes terminados em .txt.
arq?.txt? representa exatamente um caractere.
cpCopy. Copia os arquivos para o último argumento.
ls -ll de long. Exibe formato detalhado, incluindo permissões, dono, grupo e tamanho.

Se nenhum arquivo combinar com o curinga, o comando pode falhar. Por isso o script deve verificar os arquivos quando a operação for importante.

Automação 1

Preparar a estrutura de uma atividade

#!/bin/bash

base=${1:-atividade_isa}

mkdir -p "$base/documentos"
mkdir -p "$base/backup"
mkdir -p "$base/relatorios"

for numero in 1 2 3
do
  touch "$base/documentos/relatorio$numero.txt"
  touch "$base/documentos/sistema$numero.log"
done

cp "$base"/documentos/*.txt "$base/backup/"
cp "$base"/documentos/*.log "$base/relatorios/"
ls -R "$base"
OpçãoExplicação
mkdir -pp cria os diretórios necessários e aceita uma pasta já existente.
ls -RR maiúsculo significa recursive. Lista a pasta e suas subpastas.
Automação 2

Aplicar as permissões da atividade

#!/bin/bash

pasta=${1:-atividade_isa/documentos}

if [[ ! -d "$pasta" ]]; then
  echo "Diretório não encontrado: $pasta"
  exit 1
fi

chmod 600 "$pasta/relatorio1.txt"
chmod 640 "$pasta/relatorio2.txt"
chmod 644 "$pasta/relatorio3.txt"
chmod 400 "$pasta/sistema1.log"
chmod 440 "$pasta/sistema2.log"
chmod 444 "$pasta/sistema3.log"

ls -l "$pasta"
ParteExplicação
!Nega a condição. ! -d significa “não é diretório”.
exit 1Encerra o script informando erro.
chmod 640Dono: 6 = leitura 4 + escrita 2. Grupo: 4 = leitura. Outros: 0 = nenhuma.
Permissões simbólicas

Letras usadas pelo chmod

Letra ou sinalSignificado
uuser: dono do arquivo
ggroup: grupo do arquivo
oothers: demais usuários
aall: todos
r / w / xread, write e execute
+ / - / =adiciona, retira ou define exatamente
#!/bin/bash

arquivo=${1:-relatorio.txt}
chmod u=rw,g=r,o= "$arquivo"
chmod g+w "$arquivo"
chmod o-rwx "$arquivo"
ls -l "$arquivo"
Automação 3

Consultar um usuário com segurança

#!/bin/bash

read -r -p "Usuário a consultar: " usuario

if id "$usuario" > /dev/null 2>&1
then
  echo "O usuário existe."
  id "$usuario"
  getent passwd "$usuario"
else
  echo "Usuário não encontrado."
  exit 1
fi
ParteExplicação
id usuárioMostra UID, GID e grupos. Também retorna erro se a conta não existir.
> /dev/nullDescarta a saída normal.
2>&1Envia o canal 2, erros, para o mesmo destino do canal 1, saída normal.
getent passwdConsulta a base de contas usada pelo sistema.
Administração de usuários

Criar e remover exige root

#!/bin/bash

usuario=${1:-aluno}

if [[ $EUID -ne 0 ]]; then
  echo "Execute como root."
  exit 1
fi

adduser "$usuario"
ParteExplicação
$EUIDEffective User ID. No root, o valor é 0.
-neNot equal. Testa se dois números são diferentes.
adduserFerramenta amigável do Debian para criar conta, home e senha.

Cuidado

Para remover: deluser aluno preserva a home. deluser --remove-home aluno remove também a pasta pessoal. A opção longa diz exatamente o que será apagado.

Automação 4

Verificar diretórios do FHS

#!/bin/bash

diretorios=("/etc" "/home" "/var" "/tmp" "/usr" "/proc")

for pasta in "${diretorios[@]}"
do
  if [[ -d "$pasta" ]]; then
    echo "[OK] $pasta existe"
  else
    echo "[ERRO] $pasta não existe"
  fi
done
FormaExplicação
diretorios=(...)Cria um array, uma lista de valores.
"${diretorios[@]}"Percorre todos os elementos preservando cada caminho separadamente.
[OK]É apenas texto para facilitar a leitura do relatório.
Automação 5

Relatório simples com filtros

#!/bin/bash

arquivo=${1:-/var/log/dpkg.log}
termo=${2:-install}

if [[ ! -r "$arquivo" ]]; then
  echo "Não posso ler: $arquivo"
  exit 1
fi

grep -i -n "$termo" "$arquivo" > resultado.txt
quantidade=$(wc -l < resultado.txt)

echo "Linhas encontradas: $quantidade"
echo "Relatório: resultado.txt"
Opção ou formaExplicação
grep -ii de ignore case. Ignora maiúsculas e minúsculas.
grep -nn de number. Mostra o número de cada linha.
wc -ll de lines. Conta linhas.
$(comando)Executa o comando e guarda sua saída.
< resultado.txtUsa o arquivo como entrada do wc.
Automação 6

Menu para pacotes no Debian 13

#!/bin/bash

if [[ $EUID -ne 0 ]]; then
  echo "Use: sudo ./pacotes.sh"
  exit 1
fi

read -r -p "Pacote: " pacote
echo "1 - Instalar"
echo "2 - Remover"
read -r -p "Opção: " opcao

case "$opcao" in
  1) apt update && apt install "$pacote" ;;
  2) apt remove "$pacote" ;;
  *) echo "Opção inválida"; exit 1 ;;
esac
ComandoExplicação
sudo ./pacotes.shExecuta o script com privilégios administrativos.
apt updateAtualiza a lista de pacotes disponíveis. Não atualiza os programas instalados.
apt installInstala o pacote e suas dependências.
apt removeRemove o programa, mas pode preservar arquivos de configuração.
Opções do apt

Use opções somente quando compreender o efeito

FormaO que faz
apt install -y pacotey de yes. Responde “sim” automaticamente. Evite durante a aprendizagem, pois remove a confirmação.
apt purge pacoteRemove o pacote e seus arquivos de configuração administrados pelo pacote.
apt autoremoveRemove dependências instaladas automaticamente que não são mais necessárias.
apt list --installed--installed é uma opção longa. Mostra apenas pacotes instalados.
apt show pacoteMostra descrição, versão, dependências e outras informações.

O script anterior não usa -y. Assim, a turma ainda vê e confirma o que o APT pretende fazer.

Projeto de sala

Assistente da atividade avaliativa

Opção 1

Criar a árvore documentos, backup e relatorios.

Opção 2

Criar arquivos, copiar por extensão e listar com ls -R.

Opção 3

Aplicar as permissões e conferir com ls -l.

#!/bin/bash

echo "1 - Preparar diretórios e arquivos"
echo "2 - Aplicar permissões"
echo "3 - Conferir resultado"
read -r -p "Escolha: " opcao

case "$opcao" in
  1) ./preparar.sh ;;
  2) ./permissoes.sh ;;
  3) ls -R atividade_isa; ls -l atividade_isa/documentos ;;
  *) echo "Opção inválida"; exit 1 ;;
esac

; separa dois comandos na mesma linha. Para facilitar a leitura, eles também poderiam ficar em linhas diferentes.

Atividade guiada

Automação de uma tarefa já conhecida

  1. Crie assistente_isa.sh com #!/bin/bash.
  2. Receba o nome da pasta por $1, usando atividade_isa como padrão.
  3. Crie três subpastas com mkdir -p.
  4. Use for para criar três arquivos .txt e três .log.
  5. Copie cada extensão para a pasta correta.
  6. Aplique permissões diferentes com chmod.
  7. Mostre o resultado com ls -R e ls -l.
  8. Se a pasta já existir, peça confirmação antes de continuar.

Erros comuns

Como ler a mensagem e corrigir

ErroCausa provávelCorreção
Permission deniedFalta permissão de execuçãochmod +x script.sh
No such file or directoryCaminho ou nome incorretoUse pwd e ls -l
command not foundComando digitado errado ou pacote ausenteConfira o nome e use apt show
syntax error near...Bloco incompleto ou símbolo fora do lugarConfira fi, done, esac e aspas
bash -n script.sh

-n significa no execution. O Bash verifica a sintaxe sem executar os comandos.

Checklist

Antes de executar

  • Primeira linha: #!/bin/bash
  • Variáveis entre aspas: "$pasta"
  • Caminhos e nomes conferidos
  • Condições fechadas com fi
  • Laços fechados com done
  • Teste de sintaxe: bash -n
  • Permissão: chmod +x
  • Execução sem root primeiro
  • sudo apenas quando necessário
  • Saída conferida com ls e echo
